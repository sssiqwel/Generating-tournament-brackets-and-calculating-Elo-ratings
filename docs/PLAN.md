## Состав системы

| Компонент | Ответственность |
|-----------|-----------------|
| Identity | Регистрация, вход, выдача JWT, роли «Игрок», «Организатор», «Администратор» |
| Tournaments | Турниры, регистрация участников, генерация сеток (олимпийская, круговая, швейцарская), матчи, ввод результатов |
| Rating | Расчёт рейтинга Эло по событию «матч завершён», таблица лидеров |
| Feed (при наличии времени) | Лента событий, обновление сетки в реальном времени через SignalR |
| Gateway | API Gateway на YARP, единая точка входа для клиента |
| Web | Клиент на Blazor |

Инфраструктура: .NET 10, ASP.NET Core, EF Core, PostgreSQL (отдельная БД на сервис), RabbitMQ, Docker Compose, GitHub Actions, xUnit.

## Пункты продвинутого уровня

Беру после того, как полностью готов средний уровень, в указанном порядке. Каждый пункт делается отдельной веткой и Pull Request.

1. SignalR: обновление сетки и результатов в клиенте в реальном времени.
2. Redis: кэширование таблицы лидеров.
3. Интеграционные тесты API через WebApplicationFactory.
4. Outbox в Tournaments для надёжной публикации события «матч завершён».
5. Нагрузочный тест сценария ввода результатов и чтения таблицы лидеров.
6. ADR в архитектурном документе.
